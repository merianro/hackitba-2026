# hackitba-2026

Smart portfolio builder para inversores retail. Plataforma de smart finance que permite crear, personalizar y validar una cartera de inversión personalizada, con insights generados por AI.

## Estructura del repositorio

```
docs/        Documentacion de producto, analisis y specs
.cursor/     Reglas y configuracion del entorno de desarrollo
```

## Ramas

Este proyecto sigue Gitflow. Ver `.cursor/rules/gitflow.mdc` para el flujo completo.

| Rama | Proposito |
|------|-----------|
| `master` | Produccion |
| `develop` | Integracion |
| `feature/*` | Features en desarrollo |
| `release/*` | Preparacion de version |
| `hotfix/*` | Fixes urgentes |
